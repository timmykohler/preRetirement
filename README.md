# preRetirement

A Vite + React retirement timing calculator branded as **Retire When?**.

## Local development

```bash
npm install
npm run dev
```

Open the local Vite URL, usually http://localhost:5173/.

## Production build

```bash
npm run build
npm run preview
```

## GitHub Pages

This project is configured for a GitHub repository named `preRetirement`.
The Vite base path is set to `/preRetirement/` in `vite.config.js`.

After pushing to GitHub, enable Pages using:

Settings → Pages → Build and deployment → Source → GitHub Actions
